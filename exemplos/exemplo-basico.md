# Exemplo de Página HTML Completa

Copie o código abaixo, salve como `pagina.html` no seu computador e abra com dois cliques no navegador:

```html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Meu Primeiro Site</title>
</head>
<body>
    <header>
        <h1>Bem-vindo ao Meu Site</h1>
        <p>Desenvolvido durante o aprendizado de fundamentos de HTML.</p>
    </header>

    <main>
        <h2>Sobre Mim</h2>
        <p>Olá! Sou estudante de tecnologia e este é meu primeiro projeto prático.</p>

        <h2>Meus Interesses</h2>
        <ul>
            <li>Desenvolvimento Web</li>
            <li>Versionamento com Git e GitHub</li>
            <li>Tecnologia e Inovação</li>
        </ul>
    </main>

    <footer>
        <p>Projeto de aprendizagem - 2026</p>
    </footer>
</body>
</html>
```
