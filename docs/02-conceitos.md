# Módulo 02: Conceitos Essenciais de HTML

## 1. Tags e Elementos
A maioria dos elementos HTML possui:
- **Tag de abertura:** `<p>`
- **Conteúdo:** `Texto explicativo.`
- **Tag de fechamento:** `</p>`

Alguns elementos não possuem tag de fechamento (são auto-fecháveis), como `<img>` e `<br>`.

## 2. Elementos de Texto Mais Comuns
* **Títulos:** `<h1>` (título principal) até `<h6>` (subtítulo de menor nível).
* **Parágrafos:** `<p>`.
* **Destaques:** `<strong>` (negrito semântico) e `<em>` (itálico semântico).

## 3. Listas
* **Lista com marcadores (não ordenada):**
```html
<ul>
  <li>Item A</li>
  <li>Item B</li>
</ul>
```
* **Lista numerada (ordenada):**
```html
<ol>
  <li>Primeiro passo</li>
  <li>Segundo passo</li>
</ol>
