# Módulo 03: Exercícios Práticos

## Desafio: Criar sua Página de Perfil Pessoal

### Instruções:
Crie um arquivo chamado `index.html` e monte uma página contendo:
1. Um título principal `<h1>` com o seu nome.
2. Uma breve apresentação em um parágrafo `<p>`.
3. Uma lista `<ul>` com 3 tópicos que você gosta de estudar ou fazer.
4. Um link `<a>` apontando para o seu GitHub.

### Critérios de Sucesso:
- [ ] O arquivo contém `<!DOCTYPE html>`, `<head>` e `<body>`.
- [ ] A tag `<meta charset="UTF-8">` foi incluída.
- [ ] A lista e o link funcionam corretamente quando abertos no navegador.
