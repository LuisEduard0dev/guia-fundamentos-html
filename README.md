# Guia de Fundamentos de HTML para Estudantes

## Objetivo
Capacitar estudantes sem experiência a construir sua primeira página web em HTML do zero.

## Público-alvo
Estudantes e iniciantes sem conhecimento prévio em programação ou desenvolvimento web.

## Pré-requisitos
- Computador com qualquer navegador web (Chrome, Edge, Firefox, etc.)
- Editor de texto básico (Bloco de Notas) ou editor de código (VS Code)
- Nenhuma experiência prévia necessária

## Estrutura do guia
- `docs/01-introducao.md` — O que é HTML e estrutura inicial de um documento
- `docs/02-conceitos.md` — Tags essenciais, textos, links e imagens
- `docs/03-exercicios.md` — Desafio prático passo a passo
- `docs/04-referencias.md` — Links e materiais complementares
- `exemplos/exemplo-basico.md` — Exemplo completo de página comentada

## Como navegar
Recomenda-se a leitura sequencial a partir do módulo `01-introducao.md`, avançando pelos conceitos, analisando o exemplo prático e consolidando o aprendizado com o exercício proposto.
